# 8人制 審判トレーニング（試作版 v0.1）

スマホで「プレーを見て、判定の瞬間で止めて、答える」審判クイズ。保護者審判（入門）と4級審判員向け。

## 開き方

- **`referee-quiz.html` 1ファイルで動きます**（CSS・JS・問題データを1つにまとめています）。スマホに送ってブラウザで開くか、GitHub Pages / S3 などに置いてURLを共有してください。
- 3D問題（H-01）だけは three.js を CDN（jsdelivr）から読み込むので、ネット接続が必要です。WebGLが使えない端末では案内を出し、その問題をとばせます。
- 進み具合・設定・感想はその端末のブラウザ（localStorage）に保存されます。サーバーには送りません。
- **監修・確認用リンク**：URLの末尾に `#q=H-01&lv=grade4` を付けると、その問題を直接開けます（成績には記録しない復習モード）。

## UXで工夫したこと

1. **問いを先に読んでから再生**：何を見ればよいか分かった状態でプレーを見られます。判定の瞬間で自動的に止まり、そこで選択肢が出ます。
2. **誤タップを防ぐ2段階**：選択肢を選ぶ →「判定する」で確定。主ボタンは常に画面下（親指の届く位置）にあります。
3. **レベルで体験を変える**：入門は「何度でも見直し・スロー再生・ヒント・用語タップ説明」。4級は「試合に近づけて見直しは1回」「懲戒まで判断」「補助審判の問題を追加」。
4. **解説リプレイ**：答えた後、オフサイドライン・距離の円・視線・交代ゾーンなどを重ねて自動で再生します。誤答には「なぜ違うか」を、その選択肢の真下に表示します。
5. **配置問題**：ドラッグでもタップでも動かせます（キーボードの矢印キーにも対応）。答えた後は「あなた」「正解」「正解の範囲」と、ずれた距離を表示します。
6. **3Dは見る角度で判断が変わることを体験する教材**：解答前は「主審の位置」だけで見ます（ほかの視点は🔒）。解答後に副審・真横・真上へ切り替えられ、「⏱ 接触の瞬間」で止めて、ボールまでの距離と足裏の向きを確認できます。
7. **2026/27改正への配慮**：改正点の問題には 🆕 を付け、「地域大会ではまだ2025/26版の場合がある（遅くとも2027年4月1日適用）」と表示します。監修前の判断には「監修前」と明示しています。
8. **テストのしやすさ**：問題ごとに「わかりやすい／わかりにくい」を記録し、結果画面の「結果と感想をコピー」でLINEやメールに貼れます。
9. **屋外・片手操作**：高コントラスト、タップ領域は44〜56px、文字16px基準。横向きでは左にピッチ、右に問いを並べます。画面の高さが低い端末では、解説中にピッチを固定しません（読む面積を優先）。

## 動作確認（2026-10-17）

- jsdom による全10問の自動通し（入門・4級）：エラーなし
- ヘッドレス Chromium（WebGL=SwiftShader）、375×667・390×844・844×390（横向き）：全問を通しで操作し、コンソールエラーなし
- 3D：4視点・接触の瞬間・解析表示をスクリーンショットで確認
- **実機（iPhone / Android）での確認はまだです**。特に効果音（iOSの消音スイッチ）、振動（iOSは非対応）、3Dの描画速度は実機で確認が必要です。

## 既知の制約・次の課題

- 問題と解説は**監修前**です。特に H-01 の懲戒（警告）、E-01 の正解の許容範囲（±1.5m）、A-01（±1m）は監修者に確認してください。
- 3Dの人物は簡易モデル（関節を角度で動かす棒人形）です。動きの自然さより「見え方の違い」を優先しています。
- 2D/3Dとも、動きは手作業で作ったキーフレームです。問題を増やすときは `data.js` の timeline を編集します（座標は m 単位）。

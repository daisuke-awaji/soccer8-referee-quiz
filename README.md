# 8人制 審判トレーニング

8人制サッカー（U-12）の審判を担当する **保護者審判（入門）** と **4級審判員** が、スマホで「プレーを見て、判定の瞬間で止めて、答える」練習をするための Web アプリ。

> **状態: 計画（M0）**。実装はこれから。試作版 v0.1 は [`prototype/`](./prototype/) にあります。

## 準拠する規則

- JFA「8人制サッカー競技規則」（8人制で修正されていない部分は「サッカー競技規則」が適用される）
- JFA「サッカー競技規則 2026/27」（地域の大会では適用開始日が異なる場合がある）

問題の正解は一次資料の条文に基づいて作り、規則の文章だけで決まらないものは監修者の確認を経て公開します。
